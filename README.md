# InternMatch

## **Internship Search and Matching Platform**

ปัจจุบันนักศึกษาที่กำลังมองหาสถานที่ฝึกงานมักใช้หลายช่องทางในการค้นหาข้อมูล เช่น เว็บไซต์หางาน กลุ่มสื่อสังคมออนไลน์ หรือการติดต่อบริษัทโดยตรง ส่งผลให้การค้นหาสถานที่ฝึกงานใช้เวลานานและอาจไม่ได้ตำแหน่งที่ตรงกับทักษะและความสนใจของนักศึกษา

ในขณะเดียวกัน บริษัทที่เปิดรับนักศึกษาฝึกงานก็ต้องใช้เวลาในการคัดเลือกผู้สมัครจาก Resume จำนวนมาก โดยไม่สามารถทราบได้ทันทีว่าผู้สมัครมีทักษะตรงกับตำแหน่งที่ต้องการมากน้อยเพียงใด

โครงงาน InternMatch จึงถูกพัฒนาขึ้นเพื่อเป็นแพลตฟอร์มกลางที่เชื่อมโยงระหว่างนักศึกษาและบริษัท โดยใช้ระบบวิเคราะห์ทักษะ (Skill Matching) เพื่อแสดงคะแนนความเหมาะสมของผู้สมัครกับตำแหน่งฝึกงาน รวมถึงแนะนำทักษะที่ควรพัฒนาและคอร์สเรียนจากแหล่งที่น่าเชื่อถือ เพื่อช่วยให้นักศึกษาพัฒนาตนเองก่อนสมัครงาน นอกจากนี้ระบบยังช่วยให้บริษัทสามารถค้นหาผู้สมัครที่เหมาะสม พร้อมส่งการแจ้งเตือนไปยังนักศึกษาและติดตามสถานะการสมัครได้อย่างมีประสิทธิภาพ

## **ขอบเขตของโครงการ**

นักศึกษา

* สมัครสมาชิกและเข้าสู่ระบบ
* สร้างและแก้ไขโปรไฟล์
* ค้นหาตำแหน่งฝึกงาน
* สมัครฝึกงาน
* ดูคะแนน Match Score
* ดูทักษะที่ควรพัฒนา (Skill Gap Analysis)
* รับคำแนะนำคอร์สเรียนหรือสื่อการเรียนรู้จากแหล่งที่น่าเชื่อถือ โดย AI คัดเลือกให้เหมาะสมกับทักษะที่ควรพัฒนา

บริษัท

* สมัครสมาชิกและเข้าสู่ระบบ
* สร้างโปรไฟล์บริษัท
* สร้างประกาศรับนักศึกษาฝึกงาน
* ระบุคุณสมบัติและ Skills ที่ต้องการ
* ค้นหานักศึกษาที่มีคุณสมบัติเหมาะสม
* ดูคะแนน Match Score ของผู้สมัคร
* เปลี่ยนสถานะการสมัคร
* ส่งการแจ้งเตือนหรืออีเมลถึงนักศึกษา
